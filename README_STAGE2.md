## 工程来源
本工程基于本人已通过第一阶段考核的sptest工程，保留其开发历史。
第一阶段记录见README.md。本工程继续使用战队sp_middleware，版本由Git子模块固定。

## 我的任务
负责底盘失能保护、遥控运动、四轮速度控制、功率计通信与功率限制，配合云台完成隧道流程。

- 速度PID参数与输出限幅。
